# Brinebound

A first-person pirate sandbox in one web page: mine and build on voxel islands, sail and fight ships, board them for loot, and follow a story. Made with three.js; every texture, model, sound and tune is generated in code.

- **Set up on a PC and iPhone:** read `SETUP.md`.
- **Play while you work:** `npm install` once, then `npm run dev` (live reload; scan the QR code with your phone on the same Wi-Fi).
- **Publish for your phone:** `npm run publish` writes `docs/` for GitHub Pages.
- **Build files:** `npm run build` makes `dist/brinebound.html` and `dist/brinebound-offline.html`; `python3 tools/build.py` works with no installs at all.
- **Unity:** read `UNITY.md`.
- **AI assistants and new developers:** read `HANDOFF.md` first.
